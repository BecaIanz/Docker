### Backend
Tecnologia: .NET 8.0
Porta: 5215
Variáveis de ambiente:
- DB_HOST
- DB_PORT
- DB_NAME
- DB_USER
- DB_PASS

### Database
Tecnologia: PostgreSQL
Port: 5432
- POSTGRES_USER         (usuario que sera criado junto do container)
- POSTGRES_PASSWORD     (senha do usuario que sera criado junto do container)
- POSTGRES_DB           (banco de dados que sera criado junto do container)

### Frontend
Tecnologia: Node 20.0
Porta: 5173
Variáveis de ambiente:
- VITE_API_PORT     (porta da api que será usada)
- VITE_API_HOST     (host da api que será usada)
- VITE_API_ENDPOINT (endpoint da api que será usada, ex '/v1')
